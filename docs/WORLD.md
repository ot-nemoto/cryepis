# 世界の設定（オルドラ）

ベースの地図（地形）に合わせた、世界の概要・歴史・町の設定です。
町の座標は、地図を SVG にしたあとで `world/map.json` に入れます（ここでは地形の名前で場所を決めています）。

## 1. 世界の概要

- **世界の名前**: オルドラ
- **大地**: 3 つの大陸（中央大陸・西大陸・南大陸）と、2 つの島々（霧氷諸島・炎の列島）。地図の真ん中の横線が赤道で、上下の極に近づくほど寒い
- **竜気（りゅうき）**: 大昔に死んだ「始祖竜」の亡骸から、今も竜気がしみ出している。竜気を浴びた獣は魔物になる。
  地上の魔物の強さはどこでも同じで、土地によって性質が違う（砂漠は毒、雪原は群れ、など）。
  竜気がもっとも濃い場所（竜の亡骸のまわりのダンジョン）には、特に強い魔物がひそむ
- **星の巡り**: 3 か月ごとに星が巡り、勇者に与えられた星の加護（レベル）は空へ還る。
  身につけた品（アイテム）だけは残り、次の巡りでまた新しい勇者たちが旅立つ（＝シーズン）
- **冒険者ギルド**: 王国が衰えたあと、町を守るために生まれた組織。どの町にもギルドがあり、魔物退治や品物の配達の依頼を出す

## 2. 歴史（星暦）

| 時代 | 出来事 | 地形に残る跡 |
|---|---|---|
| 創世 | 創造主が海から大地を引き上げ、最初の生き物「始祖竜」が空を渡った | 3 つの大陸と島々 |
| 竜の時代 | 始祖竜と竜の一族が世界を治めた。やがて始祖竜は星と争って力尽き、中央大陸に落ちた。骨は山脈に、頭は最高峰に、牙は北東の雪山になった。心臓は南東の海に落ち、今も燃えている | 竜骨山脈・天の頂・氷牙山地・炎の列島 |
| 開拓の時代 | 西と南から海を渡った人々が、竜の血でよく肥えた大河のほとりに住みつき、王国アウレアを建てた | 黄金平原・大河 |
| 二つの王国（星暦 200〜600 年） | 東の地に魔法の国「翠国（すいこく）」が栄え、アウレアと並び立った。東の地は当時、緑の豊かな土地だった | 大砂漠の下に眠る遺跡 |
| 大災厄（星暦 600 年） | 翠国が竜の心臓の力を使う禁呪に手を出し、失敗した。東の地は一夜で焼け、砂に埋もれた。生き残った人々はオアシスに逃れた | 灼熱の大砂漠・オアシス |
| 大航海の時代（星暦 650〜900 年） | アウレアは河港を開いて船を出し、南大陸の草原と西大陸の海岸に町を作った。西大陸の赤い荒野では宝石が見つかった | 港町・鉱山町 |
| 王国の衰え（星暦 900 年〜） | 竜気が強まって魔物が増え、王国は都のまわりしか守れなくなった。町は自分たちで身を守るようになり、冒険者ギルドが生まれた | 各地の砦・ギルド |
| 現在（星暦 1024 年） | 天の頂で地鳴りが続き、「始祖竜が目覚めかけている」とうわさされている。星はそれに応えるように、巡りのたびに勇者に加護を与えはじめた | 星の巡りの始まり |

## 3. 町の配置の考え方

- **人が住む理由がある場所に町を置く**: 川のほとり・河口・港・峠・オアシス・鉱山・温泉など
- **各地に散らす**: どの大陸・島にも町があり、地形ごとに町の色が違う
- **大陸の間は船で結ぶ**: 港どうしを結ぶ船の道を作る
