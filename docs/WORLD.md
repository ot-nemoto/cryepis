# 世界の設定（オルドラ）

ベースの地図（地形）に合わせた、世界の概要・歴史・町の設定です。
町の座標は、地図を SVG にしたあとで `world/map.json` に入れます（ここでは地形の名前で場所を決めています）。

## 1. 世界の概要

創世・信仰・語り口の設定は [MYTH.md](MYTH.md) を参照。

- **世界の名前**: オルドラ
- **大地**: 3 つの大陸（中央大陸・西大陸・南大陸）と、2 つの島々（霧氷諸島・炎の列島）。地図の真ん中の横線が赤道で、上下の極に近づくほど寒い
- **竜気（りゅうき）**: 大昔に死んだ「始祖竜」の亡骸から、今も竜気がしみ出している。竜気を浴びた獣は魔物になる。
  地上の魔物は種類ごとに Lv1〜15 の強さがある（南大陸。docs/BALANCE.md）。名前や姿に合う一部の魔物にだけ性質がある（沼ヒルや砂サソリは毒、氷狼は群れ、など）。
  竜気がもっとも濃い場所（竜の亡骸のまわりのダンジョン）には、特に強い魔物がひそむ
- **星の巡り**: 3 か月ごとに星が巡り、勇者に貸された星の加護（レベル）は、名として空へ還る。
  身につけた品（アイテム）だけは残り、次の巡りでまた新しい勇者たちが旅立つ（＝シーズン）
- **冒険者ギルド**: 王国が衰えたあと、町を守るために生まれた組織。どの町にもギルドがあり、魔物退治や品物の配達の依頼を出す

## 3. 町の配置の考え方

- **人が住む理由がある場所に町を置く**: 川のほとり・河口・港・峠・オアシス・鉱山・温泉など
- **各地に散らす**: どの大陸・島にも町があり、地形ごとに町の色が違う
- **大陸の間は船で結ぶ**: 港どうしを結ぶ船の道を作る

## 3.5 開放した地域

世界は少しずつ開放していく。いまは**南大陸だけ**（サリナ・エクエス・ムラリス・カルン）が開放されていて、勇者はこの中だけを旅する。
ほかの町・ダンジョンは地図に出すが、そこへの陸路・航路・ダンジョンへの道は地図に描かず、通れない（サリナからフルメンへの航路も、まだ出していない）。
開放する町は `world/map.json` の `open`（`tools/worldgen/build_world.py` の `OPEN`）に書く。
開放していない町の依頼と、そこでしか出ないレア以上のアイテムは、データから外している（開放するときに作り直す）。
宝箱と依頼の報酬で出る common も、開放した町の店で売っている品（店の品ぞろえはどの町も同じ）。

## 3.7 属性

炎・氷・雷の 3 つ。氷→炎→雷→氷（左が右に強い）。強い属性で攻めるとダメージ 1.3 倍、弱い属性だと 0.8 倍（`season.json` の `element_rates`）。データは `world/monsters.json` の `elements`（魔物の `element`）と `world/items.json`（武器の `element`）。

| 属性 | 強い相手 | 苦手な相手 | 鉱石 | 魔物 | 武器 |
|---|---|---|---|---|---|
| 炎 | 雷 | 氷 | 熾焔鋼 | 鬼火・火トカゲ・溶岩スライム・炎の鳥 | 紅蓮草の護符（★★・装飾品。武器が無属性のとき攻撃に付く） |
| 氷 | 炎 | 雷 | 霧氷石 | 氷狼・雪男・氷の精・霜の巨人 | - |

### 鉱石

オルドラで掘り出される、不思議な力を宿した鉱石（物語の背景。`world/story.md` の「鉱石」）。炎・氷・雷の鉱石は属性の武器の素材で、`world/monsters.json` の `elements` の `ore` にも書く。どこで掘れるかは、まだ決めていない。

- **熾焔鋼（しえんこう）**【炎属性】: 常に微熱を帯び、衝撃や魔力を与えると真紅の業火を噴き上げる灼熱の鋼です。いかなる高温にも耐え、振るうだけで周囲の空気を焼き焦がす武器の素材になります。
- **霧氷石（むひょうせき）**【氷属性】: 触れた瞬間に周囲の水分や熱を奪い、凍てつかせる蒼白の結晶鉱石です。決して溶けることがなく、冷却装置のコアや極寒の冷気を放つ魔導具・氷剣に加工されます。
- **紫電鉄（しでんてつ）**【雷属性】: 極限まで高い電気伝導率を持ち、空気中の静電気や魔力を集めて紫色の放電現象を起こす暗銀色の鉄です。打撃と同時に高圧電流を流し込む兵器や、動力炉の導線に使われます。
- **宵翳鋼（しょうえいこう）**: 光を一切反射しない、夜闇のような深い漆黒の鋼です。音や気配、微弱な魔力を吸収する性質を持ち、隠密用の暗器や対魔術師用の装甲として重宝されます。
- **星屑鉄（ほしくずてつ）**: 隕石の衝突跡からのみ採掘される、銀色の地肌に無数の微細な光点が輝く宇宙由来の鉄です。極めて軽量でありながら重力や磁場に干渉する特殊な性質を帯びています。
- **陽炎石（かげろうせき）**: 周囲の熱と光を屈折させる性質を持つ、淡い琥珀色の半透明な鉱石です。この石を組み込んだ武具や装置は輪郭がゆらいで見え、光学迷彩や幻惑の媒体として使われます。

## 5. 店の品とレア

アイテムのレアリティは、依頼と同じく ★ から始まる（★ ふつう・★★ rare・★★★ epic・★★★★ legendary）。
店で売る ★ の品は、どの町も同じ（町ごとの特産はない。町の違いは、その町でしか受けられない依頼）。レア（★★ 以上）は、その町のギルドの依頼の報酬でしか出ない（宝箱からは出ない）。開放したどの町にも ★★ が 1 つ以上あり、その町にない ★★★・★★★★ が当たったときは 1 つ下のレアリティになる。
開放していない町のレア（★★〜★★★★）はデータから外している。いまの南大陸には ★★★・★★★★ のアイテムはない（当たったら ★★ になる）。

## 6. 町のギルドの依頼

どの町のギルドにも、町の特色と歴史に合わせた依頼がある（`world/quests.json` の `towns`）。依頼にはレアリティ（★〜★★★★）があり、
★ が多いほど掲示板に出にくく、報酬（経験値・お金）が多く、レアのアイテムが出やすい。★★★★ は物語の中心の町（アウレア・カエルム・アストルなど）に置く予定で、いまの南大陸にはない。
開放していない町の依頼はデータから外している（開放するときに作り直す）。いまは南大陸で 3 件（強敵の討伐だけ。WORLD の討伐）。
ふつうの討伐と配達は決まった依頼を持たず、毎回作る（#172・#173）。討伐は「{魔物}の討伐」で、★ は魔物の Lv と数で決まり、説明は町の困りごとと ★ ごとの頼み方から作る（`quests.json` の `hunts`）。
配達は決まった依頼を持たず、町ごとの荷物（`quests.json` の `deliveries` の `cargo`）から作る（#172）。★ は距離と危なさで決まり、危ない配達ほど道中で強い魔物に出会う。

| 町 | 危なさ 0（ふつうの荷物） | 危なさ 1（高価な品） | 危なさ 2（狙われる品） |
|---|---|---|---|
| サリナ | 塩・干し魚・貝の干物・海藻 | 真珠・上等な塩・南の香辛料 | 竜骨の欠片・沈没船の宝箱 |
| エクエス | 飼い葉・馬具・羊毛・チーズ | 名馬の子馬・銀の鞍・競馬祭の賞杯 | 軍馬の群れ・王家の紋章入りの鞍 |
| ムラリス | 交代の兵の食料・矢束・包帯 | 鍛えた剣・砦の地図・兵の給金 | 熾焔鋼の塊・密書 |
| カルン | 毛皮・トナカイの干し肉・燻製魚 | 白狐の毛皮・トナカイの角細工 | 霧氷石の結晶・雪男の牙 |
