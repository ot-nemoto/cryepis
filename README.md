# もののふ道中

*Warriors on the Road*

GitHub プロフィールに Pin した Gist の中身を、GitHub Actions の定期実行で生成・更新する仕組みです。
ネタ（Pin に載せる内容）ごとにスクリプトと workflow を持ち、今後ネタを追加していく想定です。

## ネタ一覧

| ネタ | Pin する Gist | 更新 | 説明 |
|---|---|---|---|
| [もののふの冒険（テキスト RPG）](#もののふの冒険テキスト-rpg) | 番付 1 つ | 毎日 JST 7:17 | もののふたちが口入れ屋の依頼をこなして育っていくのを眺める RPG。3 か月ごとのシーズン制（武具だけ持ち越す） |

## 共通の仕組み

- workflow・スクリプト・ファイルの関係と、各ファイルの使い道は [docs/DATA_FLOW.md](docs/DATA_FLOW.md) の図を参照
- `.state/` 配下のファイルの JSON 構成と項目の意味は [docs/STATE_FORMAT.md](docs/STATE_FORMAT.md) を参照
- セットアップ（Gist・PAT・Secrets / Variables）は [docs/SETUP.md](docs/SETUP.md) を参照
- 物の怪と武具の強さの決め方（大物・主・道の物の怪・武具の点数の基準・目標・検証の結果・測り方）は [docs/BALANCE.md](docs/BALANCE.md) を参照
  （ネタを追加したら、これらのドキュメントにも追記する）
- Gist の更新には `gist` スコープの Classic PAT（Secret `GIST_PAT`）を使う。Gist の ID は `.state/` のファイル（RPG は `board.json`）に記録する
- Pinned カードには Gist の**名前順で先頭のファイル**の、先頭 5 行（見出し + 4 行）ほどしか出ず、1 行 55 桁前後で切れる。
  各ネタはこの範囲に収まるように出力する（Gist のファイルは 1 つだけにする。1 行は `common.LINE_MAX` = 49 桁まで）
- 記録用のデータは `.state/` に置き、workflow の最後に github-actions[bot] 名義で master に直接コミットする（PR は通さない）。
  Variable `R2_STATE_BRANCHES` に入れたゲームは、コミットせずに Cloudflare R2 に保存する（[docs/SETUP.md](docs/SETUP.md) の「5. ゲームの状態を R2 に置く」）
- `.state/last-run` は keepalive 用。毎日コミットし、60 日無活動による scheduled workflow の停止を防ぐ
- 標準ライブラリのみで動く（Python 3.12）。GitHub API・Gist の更新・表示幅の計算は `scripts/common.py` にまとめている

## テスト・リンター・フォーマッター

```sh
python -m unittest discover -s tests   # テスト（標準ライブラリだけで動く）
CRYEPIS_SLOW_TESTS=1 python -m unittest tests.test_worldgen_stages.RegenerationTest   # 遅いテスト（45 秒ほど）
pip install ruff==0.17.4               # リンターとフォーマッター（開発と CI でだけ使う）
ruff check .                           # リンター（--fix で直せるものは直す）
ruff format .                          # フォーマッター（インデントはスペース 2。--check で確かめるだけ）
```

- 設定は `pyproject.toml`（Ruff）と `.editorconfig`（エディタ。インデントはスペース 2）
- 遅いテスト（`RegenerationTest`）は、地図の生成（`tools/worldgen/make.py`）を一時ディレクトリの中だけで通しで動かし、コミット済みの `world/map.json`・`world/map-base.svg` と完全に一致するかを確かめる（乱数の種が決まっているので、同じ地図になる）。`tools/worldgen/` を直したときや、`world/map.json` を手で直したときに動かす。ふだんのテストでは飛ばす
- PR を作った・更新したとき（と master への push・毎日の実行のあと）に、サイト公開のワークフロー（`.github/workflows/pages.yml`）が CI としてリンター・フォーマット・テストを確かめる（PR では公開しない）

## ネタを追加するとき

1. `scripts/` にスクリプトを、`tests/` にテストを追加する（Gist の更新は `common.update_gist` を使い回せる）
2. ネタごとに `.github/workflows/` に workflow を作る（`master-adventure.yml` を参考にする）
   - 最初に Test ステップ（`python -m unittest discover -s tests`）を置く
   - `.state/` に書くなら `permissions: contents: write` とコミットのステップを用意する。
     keepalive（`.state/last-run`）はどれか 1 つの毎日の workflow で更新すれば足りる（今は `master-adventure.yml`）
3. public Gist を作り（ファイルは 1 つ）、ID を管理するしくみ（`.state/` のファイルなど）を用意して Pin する
4. ドキュメントを更新する: この README の「ネタ一覧」とネタごとの節、docs/SETUP.md（Gist・Variable）、
   docs/DATA_FLOW.md（図・ファイルの表）、`.state/` に書く場合は docs/STATE_FORMAT.md（データ形式）

## もののふの冒険（テキスト RPG）

MAP の上でもののふたちが毎日それぞれ動き、町の口入れ屋の依頼をこなしながら育っていく RPG を Gist に表示します。
ゴールはなく、成長を眺める RPG です（設計は [docs/SEASON_DESIGN.md](docs/SEASON_DESIGN.md)。いまは第 1 段階のプロトタイプ）。
もののふは最大 30 人まで同時に冒険できます。見る場所は次のとおりです。

- **番付の Gist**（Pin する。Gist はこの 1 つだけ）: 今のシーズンの進み具合と、レベル・討伐数・依頼達成の番付。
  本文にはもののふごとの短い欄もある。最初の毎日の実行で自動的に作られる
- **サイト「もののふ道中」**（GitHub Pages。https://ot-nemoto.github.io/warriors-road/ ）: 最初のページは絵図（拡大・移動ができ、町や霊場の印にマウスを乗せると説明が出る。もののふの居場所はもののふのページで見る。道の上の数字は移動にかかる行動回数）。ほかに
  番付と今日の出来事、もののふの一覧、町の情報（全部の町を地方ごとのタブで切り替える。説明・口入れ屋の規模（📜 1 枚につき依頼枠 1 つ）・店・珍しい武具・道。開放していない町は説明と口入れ屋の規模だけ）、町ごとの口入れ屋の高札（地方ごとのタブ。珍しさで絞り込める）、開放した地域で手に入る武具の一覧（装備の種類ごとのタブ。珍しさで絞り込める）、開放した道に出る物の怪と主の一覧（地方ごとのタブ。その地方の街道と地形の割合の円グラフ、物の怪は Lv の順で、Lv・生息地・性質・属性・強さ。生息地で絞り込める。大物と主はそれぞれの名で絞り込める）、手引き（能力・もののふの特性・物の怪の性質・属性と相性・武具の強さ・戦いの決まりの説明）、もののふごとの詳細（ステータス・装備・持ち物・依頼・直近 30 日の冒険の記録・歴代のシーズンの記録）。
  `scripts/website.py` が `.state/` と `world/` から書き出し、`pages.yml` が毎日の実行・もののふの登録・引退のあとと、master への push のあとに公開する（書き出したファイルはコミットしない）

番付のカード:

```
🏆 シーズン1  Day 40/90  もののふ5人
Lv   🥇カイ 13 🥈ゴール… 13 🥉ボブ 13
討伐 🥇アリス 59 🥇ボブ 59 🥉カイ 57
依頼 🥇CASSIA 16 🥈ゴール… 13 🥉ボブ 12
📰 カイ: 依頼達成！森の町へ荷物を届ける（+72EXP …
```

カードでは名前を表示幅 8（全角 4 文字）までに切り詰めます。番付の Gist を開くと、上位 10 人までの順位（レベル・討伐数・依頼達成・レア武具。同じ順位でも 10 人で切る）、
今日の出来事、もののふごとの欄、歴代のシーズンの 1 位が見られます。もののふごとの欄はこんな形です。

```

  HP 117/123  攻33 防16  1587文  丸薬 3

  レア: ★★狩人の短剣
  今日: ウルフを倒した (+17EXP)、木漏れ日が揺れている
  詳細: https://<owner>.github.io/<repo>/heroes/h1.html
```

サイトのもののふごとの詳細のページ（`heroes/<id>.html`）の先頭:

```
⚔️ アリス Lv.12  S1 Day 40
📍 迷いの森 🎯 ウルフ 1/4
HP ██████████ 117/123  攻33 防16  1587文
```

続けて、ステータス・装備・持ち物、今シーズンの成績、直近 30 日の冒険の記録、歴代のシーズンの記録が載ります。

### もののふを増やす・引退させる（手動実行）

| workflow | 入力 | すること |
|---|---|---|
| *New game (add a hero)* | もののふの名前 | もののふ管理シート `.state/heroes.json` に登録し、状態を作る（Gist は作らない。詳細はサイトのもののふのページ）。冒険は次回の毎日の実行から進む |
| *Retire hero* | もののふの ID（`h1` など）または名前 | もののふを引退させる（毎日の更新の対象から外れ、番付にも出なくなる。状態は残り、サイトの詳細のページも残る。枠が 1 つ空く） |

- 手動実行は 1 件ずつ、終わってから次を実行する（`.state/` への書き込みを直列にするため、待機中に別の実行が起動すると先の待機分が取り消される）
- 現役のもののふは最大 30 人（`MAX_HEROES`）。引退したもののふは数えない。同じ名前の現役のもののふは作れない。名前は表示幅 32（全角 16 文字・半角 32 文字）まで
- もののふ管理シート `.state/heroes.json` に、もののふの ID・名前・作成日・現役かどうかが入る

### 進み方

- **世界は日本（九州〜東北）**（[docs/WORLD.md](docs/WORLD.md)。和風に作り替えている途中。物語はいったん外した。武具・物の怪の名前はまだ前の世界オルドラのまま）: 戦国のころの 25 の町。町と町は**陸路**と**航路**（船）でつながり、道ごとに移動にかかる行動回数（＝移動日数。街道は 1 日 36km）が決まっている。霊場（7 か所）は絵図に載っているが、まだ入れない（第 2 段階）
- **少しずつ開放する**: いまは**坂東だけ**（江戸・小田原・甲府・長野）を開放していて、もののふはこの中だけを旅する。ほかの町は絵図に出すが、道は描かず通れない（`map.json` の `open`）。開放していない町の依頼とレアの武具は、データから外している
- **場所は町だけ**（野外の場所はない）。道を 1 行動進むごとに、道の地形（草原・森・砂漠・雪原・海など）に合った物の怪に出会ったり、宝箱を見つけたりする
- **道の物の怪は Lv1〜15**（7 つの地方それぞれに Lv ごとに 2 体ずつ、210 体。道で出会うのは、道の両端の町がある地方の、道の地形に住む物の怪のうちもののふの Lv −3〜+1 の物の怪。同じ Lv のもののふが装備・丸薬なしで HP を 2 割減らして勝つ強さ。[docs/BALANCE.md](docs/BALANCE.md)）。名前や姿に合う一部の物の怪にだけ性質（先手・毒・群れ・凶暴・硬い・盗み）がある（半分ほどは性質なし）。強い敵は霊場にだけ出る（第 2 段階）。
  **大物**（`monsters.json` の `elite`。今は雪女・だいだらぼっち・大天狗。Lv13）は道では出会わず、町の討伐の依頼を 2 人で受けて戦う。**主**（`boss`。富士山の酒呑童子。Lv18）は、大物を全員合わせて 10 体討つと目覚め、3 人で受ける依頼が出る
  （どちらも 1 人では勝てない。依頼は物の怪のレベル以上のもののふだけが受けられ、狩り場・霊場で仲間がそろうのを待ってから一緒に戦う。人数・日数は `season.json` の `party`。#72）
- **属性**: 炎・氷・雷の 3 つ。氷→炎→雷→氷（左が右に強い）。物の怪と一部の武器に属性がある（属性なしもある。武器の属性は ★★ から）。強い属性の武器で攻めると
  ダメージ 1.3 倍、弱いと 0.8 倍（`season.json` の `element_rates`）。もののふは戦いのたびに、持ち物の中からいちばん効く武器に持ち替える
- **素早さ**: 素早いほうが先に攻撃し、相手の 2 倍以上素早ければ 2 回攻撃する（性質「先手」の物の怪は、素早さに関係なく先）。
  もののふの素早さは基本 6 で、重い装備は遅くなり、軽い装備は速くなる
- **能力の伸び**: HP は Lv1 の 30 から毎レベル +8。攻撃・防御・素早さ・器用さは Lv1 の 6 から Lv20 の 30 まで、
  能力ごとに伸びる時期が違う（攻撃＝早熟・防御＝晩成・素早さ＝中盤・器用さ＝平均。`season.json` の `growth` に Lv1〜20 の値を書く）
- **会心の一撃**: 器用さ ÷ 150 の確率（Lv1 で 4%、Lv20 で 20%）で、ダメージが 3 倍になる（`season.json` の `critical`）。物の怪にも器用さがある
- **特性**: もののふを作るときにランダムで決まり、シーズンが変わっても変わらない（`season.json` の `hero_traits`）。
  怪力（攻撃）・鉄壁（防御）・俊足（素早さ）・技巧（器用さ）は、その能力の Lv1 からの伸びが 1.25 倍（Lv20 で 36）。
  怪力は HP の伸びが 0.7 倍になる（Lv20 で 136）。頑丈は HP の伸びが 1.375 倍（毎レベル +11）で、攻撃の伸びが 0.9 倍になる（Lv20 で 28）。
  倍率は 1 より小さくもできる（弱みのある特性）。強運は能力は伸びず、宝箱や報酬で何も出なかったときに 1 度だけ引き直す
- **最大レベルは 20**（`season.json` の `max_level`）
- **最初の町はランダム**: 開放した町のうち 3 つ（`starts`。江戸・小田原・長野）から、もののふごとに決める。シーズンが変わると決め直す
- 1 日の**行動回数**は毎日同じ（`world/season.json` の `actions_per_day`、今は 3 回）。何が起きるか（物の怪・宝箱・景色など）が乱数で決まる
- 町に着いても HP は回復しない。依頼を持っていないとき、HP が減っていれば旅籠で休憩する（1 行動と 20文で全回復。`season.json` の `inn`）。店で今より良い装備と丸薬を買う。口入れ屋の高札（町ごとに全員共通。日をまたいで残る）から、
  依頼を受ける。**依頼を受けるのは 1 日 1 回**で、受けるのに行動回数は使わない。依頼がなければ、となりの町へ旅をする（報酬なし）
- 依頼ごとに**必要な行動力**が決まっていて、毎日の行動回数でこなしていく（何日かかってもよく、期限はない。ふつう、失敗するのは力尽きたときだけ）
  - 配達: 届け先までの距離（道の行動回数の合計）
  - 討伐: 行き（狩り場まで。道の長さの半分、最大 2）＋ 討伐 1（何体いても 1 行動で、1 体ずつ連戦する。HP は減ったまま次へ）＋ 帰り
- 道の戦いは 1 体だけ。何体かと戦うのは討伐の依頼だけで、倒すたびに経験値とお金が入る（途中で力尽きても、倒した分は残る）
- 依頼が終わってその日の行動回数が余ったら、性格で決まった行動をする: 休む（行動力を溜める。最大 2 日分。依頼の途中でその日の行動回数を使い切ったときと旅籠の休憩に使う）・町の周りを散策する（散策だけの表 `stroll_events`。強い物の怪と宝箱が多い）・となりの町へ移動する
- 町に着いてから 7 日たったら（最後に別の町に着いた日を 0 日目として数える）、その日は依頼を受けず、となりの町へ旅に出る（`season.json` の `stay_days_max`。依頼の途中なら、帰ってきた次の日の朝）
- **性格**: もののふを作るときにランダムで決まり、シーズンが変わっても変わらない（`season.json` の `personalities`。慎重・勇猛・倹約・勤勉・冒険・策士）。旅籠に泊まる HP・丸薬を使う HP・装備より先に買う丸薬の数・選ぶ依頼（討伐の Lv の範囲と ★。配達は Lv を見ない。範囲に合う依頼がなければ、範囲より弱い依頼のうちいちばん近い Lv のもの）・その日の残りの行動が変わる（サイトの手引きの「もののふの性格」）
- 口入れ屋の高札は町ごとに枠の数が決まっていて（王都 6、港や大きな町 5、ふつうの町 4、小さな村や砦 3。`map.json` の `quests_per_day`）、**早い者勝ち**。ほかのもののふが受けた依頼は受けられず（受注中）、誰も受けないまま 3 日たった依頼は入れ替わる（`season.json` の `quest_open_days`）。達成された依頼は翌日に新しい依頼に入れ替わり、失敗した依頼は翌日にまた受け付ける。受けられる依頼がなければ、となりの町へ旅に出る。毎日、もののふを進める順番を混ぜるので、いつも同じもののふが先になることはない
- 口入れ屋には、町の特色に合わせた**町の依頼**と、どの町にもある**共通の依頼**がある。依頼にはレアリティ（★〜★★★★）があり、★ が多いほど出にくく、報酬が多く、レアの武具が出やすい（[docs/WORLD.md](docs/WORLD.md)）
- 依頼は**討伐**（町から出る道の 1 本の近くで、その道に出る物の怪を指定の数だけ倒し、町に戻って報告する）と**配達**（別の町へ届ける。報告は届け先の町）。報告するとお金（配達は討伐の 2 倍。経験値は物の怪を倒したときだけ入る）と、
  確率で武具がもらえる。共通の討伐の ★ は、物の怪の Lv ×（数 + 1）で決まる（15 以下 ★・40 以下 ★★・それより上 ★★★）。討伐は「{物の怪}の討伐」で、説明は町の困りごとと ★ ごとの頼み方から作る。町の決まった依頼は大物の討伐だけ。配達は町の荷物から作り、★ は距離 ×（危なさ + 1）で決まる（4 以下 ★・8 以下 ★★・それより上 ★★★）。危なさ 1・2 の配達を運んでいる間は、道で出会う物の怪の Lv が 2・4 上がる（危なさ 2 は Lv5 から）（今はレア（★★ 以上）の配布を止めている。`season.json` の `rare_drops` が false の間は、レアが当たっても何も出ない。common は出る）
- 道の出来事は、戦闘・宝箱（common の装備・お金・丸薬）・景色のどれか（起こりやすさは `season.json` の `road_events`。宝箱のお金は、道でも散策でも、もののふの Lv に関係なく 10〜30文で、`treasure_gold`）
- 宝箱と依頼の報酬で出る common の装備は、開放した町の店で売っている品。店の品ぞろえはどの町も同じ（町ごとの特産はない。町の違いは、その町でしか受けられない依頼）
- 丸薬は、戦いで HP が性格で決まった割合を下回ったとき自動で使う（最大 HP の 50% ぶん回復。HP が 0 になったら、丸薬があっても力尽きる）。道の途中で HP が減っても引き返さない（依頼が終わるか力尽きるまで進む）
- 力尽きたら依頼は失敗になり、最後に寄った町で目を覚ます（お金・持ち物は減らない。その日はもう行動しない）。失敗した依頼の報酬はもらえないが、それまでの戦いの経験値・お金は残る（[docs/SEASON_DESIGN.md](docs/SEASON_DESIGN.md) の「依頼の進め方」）
- 手に入れた武具は持ち物に入り、部位（武器・頭・胴・御守）ごとに ★ の多いもの（同じなら点数の高いもの）を自動で装備する。持てる数は武器 3・頭 1・胴 1・御守 3（`season.json` の `carry`）で、超えた分は町の口入れ屋の蔵に預ける（どの町でも出し入れでき、依頼の物の怪に効くスキルの装備と入れ替える）
- **装備のスキル**: ★★ 以上の装備には、町の鍛冶屋でお金を払ってスキルを付けられる（★★ 500文・★★★ 800文・★★★★ 1000文、1 日 1 回）。部位ごとに 10 個（対策・攻め・守り・回復・旅・お金・成長の 7 系統）からランダムで付き、点数には入らない。付けるかどうか（装備の珍しさと余裕）と、部位ごとの優先スキルは性格で決まる。持っている装備を ★ の多い順に見て、優先スキルの付いていない最初の装備に付ける（優先スキルが付いたら、もう変えない）（`items.json` の `skills`、`season.json` の `personalities` の `skill`）
- **シーズン**は 3 か月（`world/season.json` の `start` と `months`）。シーズンが変わると記録を残し、
  **武具以外**（レベル・お金・丸薬・位置・依頼）を最初に戻す。武具は多少の助けになる程度に抑えている
- 乱数は「日付＋シーズン＋もののふの ID」を種にするので、もののふごとに展開が違う。同じ日に何度実行しても結果は同じで、その日の分を処理済みなら進めない（Gist の表示だけ更新する）
- workflow が動かなかった日は、次の実行でさかのぼって 1 日ずつ進める（最大 7 日分）
- 1 人のもののふの更新（状態ファイルが読めないなど）が失敗しても、ほかのもののふは進める。番付の Gist の更新が失敗しても、状態は保存する（どちらも、失敗があれば workflow は失敗で終わる）
- 始めるには Secret `GIST_PAT` を登録して（番付の Gist に使う）、*New game* を実行する（[docs/SETUP.md](docs/SETUP.md)）。もののふがいない間、毎日の実行は何もしない

### 世界を広げる（world/ の編集）

| ファイル | 中身 |
|---|---|
| `world/season.json` | シーズンの長さ・初期ステータス・レベルアップ・1 日の行動回数・丸薬・宝箱のドロップ表など |
| `world/map.json` | 場所（町・霊場）と道、開放した町（`open`。もののふが行ける町。ほかの町への道は描かず通れない）、最初の町の候補（`starts`。開放した町から）、地図の大きさとベースの地図（`layout`）。町には名前・呼び名（`alias`）・地域（`region`）・説明（`text`。サイトの町のページに出す）・店・地図の座標（`pos`。1600×1000、北が上）。道には種類（`kind`: 陸路 `land`・航路 `sea`・霊場への道 `trail`）・行動回数（`distance`）・地形の割合（`terrain`。どの地形の物の怪が出るかと、景色の文が決まる）・地図に描く線（`path`）。地方（`areas`: ID・名前・英語名）と、場所ごとの地方（`area`）と英語名（`en`）もある。いまは町 25（開放 4）・霊場 7・陸路 27・航路 4（開放した道は陸路 3） |
| `world/map-base.svg` | ベースの地図（地形の絵） |
| `tools/worldgen/` | 地図づくりのスクリプト。`python tools/worldgen/make.py` で地形・陸路・航路・行動回数を作り直し、`world/map.json` と `world/map-base.svg` を書き出す（日本の海岸線は `japan.py`、町の配置と道の表は `places.py`、呼び名は `names.py`、山脈・地域・川は `terrain.py`） |
| `world/monsters.json` | 物の怪（道で出会う地方 `area`・住む地形 `terrain`（その地方の道にある地形）・性質 `trait`・属性 `element`・素早さ `spd`・器用さ `dex`。経験値とお金は書かず、能力から計算する: `season.json` の `monster_reward`）と、性質の一覧（`traits`。`score` は強さ点で足す値、`gold_rate` は倒したときのお金の倍率。盗みの物の怪は多い）、属性と相性（`elements`: 名前と、強い相手の属性 `strong`） |
| `world/items.json` | 武具と珍しさ（common / rare / epic / legendary。印は ★〜★★★★ で、依頼のレアリティと同じく ★ から始まる）。説明（`text`。任意で、100 文字以内。サイトの武具のページの名前の下に出る）。店で売るもの（common）は `price` を書く。レア（rare 以上）は `towns` に書いた町の依頼の報酬でしか出ない（レベルの制限なし）。町ごとの特産とレアは [docs/WORLD.md](docs/WORLD.md) |
| `world/quests.json` | 口入れ屋の依頼。1 行動あたりの報酬（`reward`）、レアリティ（`ranks`: ★〜★★★★ の出やすさ・報酬の倍率・武具のドロップ表）、共通の依頼（`templates`）、町ごとの依頼（`towns`: 名前・内容・口入れ屋の言葉。開放した町だけに書く。いまは南大陸の 3 件。大物の討伐だけ） |

- 参照はすべて ID。編集したら `python -m unittest discover -s tests` で確かめる（`tests/test_world.py` がデータの誤りを、
  `tests/test_game.py` の BalanceTest がシーズン末のレベルや依頼の成功率を調べる）
- データに誤りがあると毎日の実行の Test で止まり、その日の冒険は進まない（壊れたデータで進むことはない）
- 場所や武具を消しても、もののふの状態は壊れない（消えた場所にいるもののふは最初の町に戻り、消えた依頼は取り消す）
- 武具の点数（`season.json` の `item_points`）が 0 点から珍しさの上限までに入らないと検証で止まる（★ 1 点・★★ 2 点・★★★ 2 点・★★★★ 3 点まで。属性は 1 点。★ に属性は付けられない）
