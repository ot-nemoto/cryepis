# クリエピス戦記

灯暦 1024 年。天の頂で地鳴りが続き、人々は「竜が、なにかを感じとっている」とささやき合う。
それに応えるように、竜は星の巡りのたびに、選ばれた者たちへ加護を貸しはじめた。
加護を受けた勇者たちは、冒険者ギルドの依頼をこなしながら、竜気に満ちた世界オルドラを旅していく。

## はじまりの話

むかしむかし、まだ何もなかったころの話。あるのは、海ばかりだった。
その海は、ただの水ではなかった。海は「おおうみ」といって、からだがあった。けれど、名前も顔もなかった。だから人は今でも、おおうみを「名のないひと」と呼ぶ。

おおうみは、ひとりでいるのがさびしくなって、からだの底から、てのひらをさしあげた。
てのひらからは、水がしたたり落ちて、川になった。てのひらの上には、土と石が残った。それが、大地だ。大地は、おおうみのてのひらだから、あたたかい。

空には、星があった。星は、数えるためにある。ひとつ、ふたつと数えて、日がたち、月がたち、年がたつ。生まれたものは育ち、育ったものは、いつかおおうみのふところへ帰る。これを「めぐり」という。

おおうみは、大地をさしあげてくたびれて、ゆっくりと眠りについた。それきり、ひとことも話さない。けれど、海は今もうねっている。うねっているうちは、おおうみは、そこにいる。

そのころ、大地には、もう人がいた。今の人より、ずっと前の人だ。
前の人のそばには、竜がいた。人は、それを「竜」と呼ぶ。けれど、その姿を見た者はいない。翼のある大きな竜だと言う者もいれば、形などない、神さまのようなものだと言う者もいる。竜がどこから来たのかも、誰も知らない。前の人がつくった、と言う年寄りもいる。
竜は、いのち、かぎり、こころざし、この三つをいっぺんに持っていた、という。

前の人は、竜の力を欲しがった。ひとりじめしようとして、人と人とで争った。
空が焼け、星のかけらが降った。前の人は、みな海へ帰った。竜も傷ついて、大地に落ちた、という。中央の大陸を走る山なみは、そのとき落ちた竜の骨だと言われる。

竜は、ひとりで、長いあいだ眠った。どれだけ眠ったのかは、誰にも数えられない。星の数よりも長かった、と年寄りは言う。
大地の傷がふさがったころ、竜は目を覚ました。そして、北東の雪山の氷の中から、人を出した。百五十人だった。
人は、五十人ずつ、三つの里に分かれた。里には、それぞれ長がいた。長は、竜が何者で、自分たちが何者なのかを知っていた、という。三つが集まれば、どれほどの力になり、どれほどの災いになるのかも。
長は、知っていることを、里の教えにして伝えた。どの里も、竜の言葉を聞いたのは、自分たちだけだと言う。

そのあと、竜は、三つに分かれた、という。人は、それを頭・牙・心臓と呼ぶ。いちばん高い山には頭が、人が出てきた北東の雪山には牙が、南東の海には心臓がある。心臓は、今も海の底で燃えているそうな。
竜は、海へ帰らなかった。海へ帰らないものは、死にきれない。死にきれない竜から、竜気がしみ出して、それを浴びた獣は、魔物になる、と言われる。

人が死ぬと、形は大地に残り、名は竜へ還り、からだは海へ帰る。

そして、いま。竜が、また人に加護を貸しはじめた。
「竜の火は、ただではない」と、年寄りは言う。

## 世界オルドラ

- **大地**: 3 つの大陸（中央大陸・西大陸・南大陸）と、2 つの島々（霧氷諸島・炎の列島）。地図の真ん中が赤道で、上下の極に近づくほど寒い
- **竜気（りゅうき）**: 三つに分かれて、死にきれない竜（始祖竜）から、今も竜気がしみ出していると言われる。竜気を浴びた獣は魔物になる。土地によって出る魔物とその性質が違い、ひ弱な獣から手ごわい魔物までいる（砂漠は毒、雪原は群れ、など）
- **星の巡り**: 3 か月ごとに星が巡る。巡りが変わると、竜が勇者に貸した加護（レベル）は、名として竜へ還る。形ある品だけは大地に残り、次の巡りでまた新しい勇者たちが旅立つ
- **冒険者ギルド**: 王国が衰えたあと、町を守るために生まれた組織。どの町にもギルドがあり、魔物退治や品物の配達の依頼を出す

## 三つの教え

オルドラには、三つの大きな教えがある。もとをたどると、はじめの三つの里の、長の教えに行きつく。どの教えも、竜の言葉を正しく受けついだのは自分たちだ、と言う。
長の言葉は、代を重ねるうちに、言い伝えになった。教えのいちばん上に立つ者たちは、今も古い言い伝えを持っているという。けれど、それが何を言っているのか、本当のところは、もう誰にも分からない。残ったのは、竜への思いだけだ。竜をどう見るかは、教えによってちがう。どれが本当かは、誰も知らない。

- **星読み**: 星の巡りを読み、暦を守る人々。竜は、眠らせておくべき、おそろしいものだと教える。加護は竜から借りたもので、かならず返さなければならない。竜気は呪いだという。霧氷の修道院（アストル）を、本山とする
- **竜の民**: 竜を、人を生んだ親とあおぐ人々。竜とともに生き、竜のいのちを絶やさないように、と教える。加護は親から子への贈り物で、竜気もまた贈り物だという。竜の火を、絶やさずにつなぐ
- **王国の教え**: 竜の力は、人が法で治めて、使いこなすべきものだと教える。王は、おおうみに代わって法を守る者とされる。加護は使うべき力で、竜気は治めきれずにこぼれた災いだという

このほか、山や川や石をまつる、土地の古い信仰がある。商いをする人々は、どの教えにも深入りしない。

三つの教えは、おたがいに、にらみあっていると言われている。星読みは竜の民を抑え、竜の民の熱は王国の秩序を揺るがし、王国は星読みを従わせようとする、と。誰かが勝てば、別の誰かが負ける。だから、どの教えも、決定的には勝てない。

それぞれの教えは、竜のからだの欠片を、守っているという。本当かどうかは分からない。星読みは牙の欠片を、竜の民は心臓の熾を、王国は頭骨の冠を。三つの欠片がそろえば、大きな力になり、同時に大きな災いになる。それだけは、どの教えの言い伝えにも残っている。けれど、どう受け止めたかは、教えによってちがう。

- **星読み**: 災いを重く見る。そろう前に、三つとも自分たちが預かって氷の底に封じ、竜を永遠に眠らせるべきだ、と言う
- **竜の民**: 力を信じる。災いは、竜をばらばらにした報いだという。一つに戻して竜を救えば、災いは起きない、と言う
- **王国の教え**: 力は、意志で治められると考える。頭骨の冠をかぶった王が三つをそろえて治めれば、災いを抑えて、力だけを使える、と言う

どの教えも、自分たちなら災いを避けられると信じている。だから、ほかの教えには渡せない。ほかの教えが取りにくる、と、どの教えも思っている。

いま、王国は衰えている。竜が、また人に加護を貸しはじめた。星読みは勇者を「竜に借りのある者」と呼び、竜の民は「竜の子」と呼び、王国の教えは「使うべき力」と呼ぶ。冒険者ギルドだけは、どの教えの依頼でも、金を払えば受ける。

## 鉱石

オルドラの大地からは、不思議な力を宿した鉱石が掘り出される。鉱石の多くは、竜のからだや、空から降ったかけらから生まれたと言われる。炎・氷・雷の力を持つ鉱石は、属性の武器の素材になる。

- **熾焔鋼（しえんこう）**【炎属性】: 竜の心臓の熱が、地の底で固まったものと言われる、赤い鋼。いつもほのかにあたたかく、叩くと火を噴く。どんな熱にも負けないので、炎の武器の素材になる。
- **霧氷石（むひょうせき）**【氷属性】: 竜の牙の冷たさが、地の底で結晶になったものと言われる、青白い石。触れると、まわりの熱と水気を奪って凍らせる。決して溶けないので、氷の剣や、冷たい道具の芯になる。
- **紫電鉄（しでんてつ）**【雷属性】: 竜の頭のひらめきが、地の底で鉄になったものと言われる、暗い銀色の鉄。空気や魔力を集めて、紫の火花を散らす。打つと同時に雷が走る武器や、雷で動く道具になる。
- **宵翳鋼（しょうえいこう）**: 光を返さない、夜のように黒い鋼。音も気配も吸いこんでしまう。おおうみが大地をさしあげたとき、海の底に残った名残だという。こっそり動く者や、魔法使いと戦う者が、好んで使う。
- **星屑鉄（ほしくずてつ）**: 星のかけらが降った跡からだけ掘れる、銀色の地肌に光の粒が散る鉄。前の人が竜をめぐって争ったとき、焼けた空から降ってきたものだという。とても軽く、重さや磁気に、不思議なふるまいをする。
- **陽炎石（かげろうせき）**: 熱と光をゆがめる、淡い琥珀色の半透明の石。竜の吐息の名残だという。この石を組みこんだ武具は、輪郭がゆらいで見える。幻をつくる道具の芯になる。

## 歴史

年は「灯暦」で数える。竜が目を覚まして人を出し、人が大地で、はじめて火をともした年が、元年だ。その火をくれたのは竜だ、とどの教えも言うが、どの里に最初にくれたのかは、言うことがちがう。

| 時代 | 出来事 |
|---|---|
| 創世 | 海そのものである「おおうみ」が、てのひらをさしあげて大地を作った。おおうみは、それきり眠りについた |
| 前の人の時代 | 今の人よりずっと前に、人がいた。そのそばには竜がいた。前の人は竜の力をひとりじめしようとして争い、空が焼け、星のかけらが降った。前の人はみな海へ帰り、竜も傷ついて大地に落ちた。竜の骨は山脈になった |
| 長い眠り | 竜は、数えきれないほど長いあいだ眠った。大地の傷は、そのあいだに、ゆっくりふさがった |
| 目覚め（灯暦の元年） | 竜が目を覚まし、北東の雪山の氷の中から百五十人の人を出した。人は五十人ずつ三つの里に分かれ、はじめて火をともした。里の長は、竜のことを教えにして伝えた。竜はそのあと、三つ（頭・牙・心臓）に分かれた、という。頭は最高峰に、牙は北東の雪山に、心臓は南東の海に。死にきれない竜からは、竜気がしみ出している |
| 開拓の時代（灯暦の元年〜） | 三つの里の人々は増えて、大地に広がった。頭の里の人々は、竜の血でよく肥えた大河のほとりに住みつき、王国アウレアを建てた。心臓の里（炎の列島）の人々の一部は、海を渡って大陸にも住みついた |
| 二つの王国（灯暦 200〜600 年） | 東の地に魔法の国「翠国」が栄え、アウレアと並び立った |
| 骨の禁令（灯暦 320 年） | 王国が、竜の骨のそばでの骨葬を禁じた。大陸の竜の民の多くは従わず、東へ移った |
| 大災厄（灯暦 600 年） | 翠国が竜の心臓の力を使う禁呪に手を出し、失敗した。東の地は一夜で焼け、砂に埋もれた（誰のせいかは、教えによって言うことが違う） |
| 霧氷の裁き（灯暦 610 年ごろ〜） | 星読みが霧氷の修道院で、竜の民を異端として裁き、骨と遺品を氷に封じた。大陸の竜の民の多くは、砂漠や雨林、心臓の里のある炎の列島へ散った |
| 大航海の時代（灯暦 650〜900 年） | アウレアは船を出し、南大陸の草原と西大陸の海岸に町を作った |
| 王国の衰え（灯暦 900 年〜） | 竜気が強まって魔物が増え、王国は都のまわりしか守れなくなった。町は自分たちで身を守るようになり、冒険者ギルドが生まれた |
| 現在（灯暦 1024 年） | 天の頂で地鳴りが続き、竜が勇者に加護を貸しはじめた |

## 勇者たちの旅

- 勇者は毎朝、決まった回数だけ行動する。道を進むと、魔物に出会ったり、宝箱を見つけたりする
- 町に着くと傷が癒え、店で装備と回復薬を買い、ギルドの掲示板から依頼を 1 つ受ける。依頼は早い者勝ち
- 依頼をこなすとお金が入り、町によっては珍しい装備（★★ 以上）も手に入る
- 3 か月で星が巡ると、レベルは 1 に戻る。手に入れた装備だけは、次の巡りに持ち越せる
