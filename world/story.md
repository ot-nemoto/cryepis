# クリエピス戦記

星暦 1024 年。天の頂で地鳴りが続き、人々は「始祖竜が目覚めかけている」とささやき合う。
それに応えるように、星は巡りのたびに、選ばれた者たちへ加護を貸しはじめた。
加護を受けた勇者たちは、冒険者ギルドの依頼をこなしながら、竜気に満ちた世界オルドラを旅していく。

## はじまりの話

むかしむかし、まだ何もなかったころの話。あるのは、海ばかりだった。
その海は、ただの水ではなかった。海は「おおうみ」といって、からだがあった。けれど、名前も顔もなかった。だから人は今でも、おおうみを「名のないひと」と呼ぶ。

おおうみは、ひとりでいるのがさびしくなって、からだの底から、てのひらをさしあげた。
てのひらからは、水がしたたり落ちて、川になった。てのひらの上には、土と石が残った。それが、大地だ。大地は、おおうみのてのひらだから、あたたかい。

おおうみは、てのひらの上に、星をならべた。星は、数えるためにある。ひとつ、ふたつと数えて、日がたち、月がたち、年がたつ。生まれたものは育ち、育ったものは、いつかおおうみのふところへ帰る。これを「めぐり」という。めぐりを守るのが、星のしごとだ。

いちばん最後に、おおうみは、ふうっと息を吹いた。息は、ひとつの生き物になった。それが、はじまりの竜だ。
竜は、いのち、かぎり、こころざし、この三つをいっぺんに持っていた。そんな生き物は、あとにも先にも、竜だけだった。竜だけが、空も、大地も、海も、どこへでも行けた。

おおうみは、息を吹いてくたびれて、ゆっくりと眠りについた。それきり、ひとことも話さない。けれど、海は今もうねっている。うねっているうちは、おおうみは、そこにいる。

そのあとの話は、土地によって、ちがう。

竜は、星といさかいをした。どうしていさかいになったのかは、話す人によって、ちがう。ただ、ここだけは、どこの話も同じだ。竜も星も、傷ついた。星のいくつかは、空から落ちて、星屑になった。竜は、力つきて、大地に落ちた。
落ちたとき、竜は三つにちぎれた。頭は、いちばん高い山になった。牙は、北東の雪山になった。心臓は、南東の海に落ちて、今も燃えている。

竜は、大地に落ちたので、海へ帰れなかった。海へ帰れないものは、死にきれない。死にきれない竜から、竜気がしみ出して、それを浴びた獣は、魔物になる。

人は、そのずっとあと、海のむこうから渡ってきた。人が死ぬと、形は大地に残り、名は空へ還り、からだは海へ帰る。

そして、いま。星が、また人に声をかけはじめた。
「星の灯りは、ただではない」と、年寄りは言う。

## 世界オルドラ

- **大地**: 3 つの大陸（中央大陸・西大陸・南大陸）と、2 つの島々（霧氷諸島・炎の列島）。地図の真ん中が赤道で、上下の極に近づくほど寒い
- **竜気（りゅうき）**: 海へ帰れず、死にきれない「始祖竜」の亡骸から、今も竜気がしみ出している。竜気を浴びた獣は魔物になる。土地によって出る魔物とその性質が違い、ひ弱な獣から手ごわい魔物までいる（砂漠は毒、雪原は群れ、など）
- **星の巡り**: 3 か月ごとに星が巡り、勇者に貸された星の加護（レベル）は、名として空へ還る。形ある品だけは大地に残り、次の巡りでまた新しい勇者たちが旅立つ
- **冒険者ギルド**: 王国が衰えたあと、町を守るために生まれた組織。どの町にもギルドがあり、魔物退治や品物の配達の依頼を出す

## 三つの教え

オルドラには、三つの大きな教えがある。竜と星のいさかいが、なぜ起きたのか。それぞれの教えが、ちがうことを語る。どれが本当かは、誰も知らない。

- **星読み**: 星の巡りを読み、暦を守る人々。竜は傲り、めぐりを呑もうとした、と教える。竜気は呪い、星の加護は祝福だという。霧氷の修道院（アストル）を、本山とする
- **竜の民**: 始祖竜を祖とあおぐ人々。竜は生き物をめぐりから解き放とうとして、星は看守だった、と教える。竜気は贈り物、星の加護は首輪だという。竜の火を、絶やさずにつなぐ
- **王国の教え**: 王と法を、おおうみに代わるものとする教え。竜も星も、おおうみがつくったものにすぎない、と教える。おおうみが目を覚ます日に備えて、法と秩序を守る

このほか、山や川や石をまつる、土地の古い信仰がある。商いをする人々は、どの教えにも深入りしない。

三つの教えは、おたがいに、にらみあっていると言われている。星読みは竜の民を抑え、竜の民の熱は王国の秩序を揺るがし、王国は星読みを従わせようとする、と。誰かが勝てば、別の誰かが負ける。だから、どの教えも、決定的には勝てない。

それぞれの教えは、竜のからだの欠片を、守っているという。本当かどうかは分からない。星読みは牙の欠片を、竜の民は心臓の熾を、王国は頭骨の冠を。ほかの教えが取りにくる、と、どの教えも思っている。

いま、王国は衰えている。星が、また人に声をかけはじめた。星読みは勇者を「祝福された者」と呼び、竜の民は「首輪をつけられた者」と呼び、王国の教えは「使うべき力」と呼ぶ。冒険者ギルドだけは、どの教えの依頼でも、金を払えば受ける。

## 鉱石

オルドラの大地からは、不思議な力を宿した鉱石が掘り出される。鉱石の多くは、竜のからだや、落ちた星のかけらから生まれたと言われる。炎・氷・雷の力を持つ鉱石は、属性の武器の素材になる。

- **熾焔鋼（しえんこう）**【炎属性】: 竜の心臓の熱が、地の底で固まったものと言われる、赤い鋼。いつもほのかにあたたかく、叩くと火を噴く。どんな熱にも負けないので、炎の武器の素材になる。
- **霧氷石（むひょうせき）**【氷属性】: 竜の牙の冷たさが、地の底で結晶になったものと言われる、青白い石。触れると、まわりの熱と水気を奪って凍らせる。決して溶けないので、氷の剣や、冷たい道具の芯になる。
- **紫電鉄（しでんてつ）**【雷属性】: 竜の頭のひらめきが、地の底で鉄になったものと言われる、暗い銀色の鉄。空気や魔力を集めて、紫の火花を散らす。打つと同時に雷が走る武器や、雷で動く道具になる。
- **宵翳鋼（しょうえいこう）**: 光を返さない、夜のように黒い鋼。音も気配も吸いこんでしまう。おおうみが大地をさしあげたとき、海の底に残った名残だという。こっそり動く者や、魔法使いと戦う者が、好んで使う。
- **星屑鉄（ほしくずてつ）**: 星が落ちた跡からだけ掘れる、銀色の地肌に光の粒が散る鉄。竜といさかいをして落ちた、星の亡骸だという。とても軽く、重さや磁気に、不思議なふるまいをする。
- **陽炎石（かげろうせき）**: 熱と光をゆがめる、淡い琥珀色の半透明の石。竜の吐息の名残だという。この石を組みこんだ武具は、輪郭がゆらいで見える。幻をつくる道具の芯になる。

## 歴史

| 時代 | 出来事 |
|---|---|
| 創世 | 海そのものである「おおうみ」が、てのひらをさしあげて大地を作った。てのひらの上に星を置き、最後に息を吹くと、最初の生き物「始祖竜」が生まれた。おおうみは、それきり眠りについた |
| 竜の時代 | 始祖竜と竜の一族が世界を治めた。やがて始祖竜は星といさかいをして力尽き、中央大陸に落ちた。骨は山脈に、頭は最高峰に、牙は北東の雪山になった。心臓は南東の海に落ち、今も燃えている。海へ帰れない始祖竜は、死にきれないまま、竜気をしみ出させている（いさかいの理由は、土地によって語りが違う） |
| 開拓の時代 | 西と南から海を渡った人々が、竜の血でよく肥えた大河のほとりに住みつき、王国アウレアを建てた |
| 二つの王国（星暦 200〜600 年） | 東の地に魔法の国「翠国」が栄え、アウレアと並び立った |
| 骨の禁令（星暦 320 年） | 王国が、竜の骨のそばでの骨葬を禁じた。竜の民の多くは従わず、東へ移った |
| 大災厄（星暦 600 年） | 翠国が竜の心臓の力を使う禁呪に手を出し、失敗した。東の地は一夜で焼け、砂に埋もれた（誰のせいかは、教えによって言うことが違う） |
| 霧氷の裁き（星暦 610 年ごろ〜） | 星読みが霧氷の修道院で、竜の民を異端として裁き、骨と遺品を氷に封じた。竜の民の多くは、砂漠や雨林、炎の列島へ散った |
| 大航海の時代（星暦 650〜900 年） | アウレアは船を出し、南大陸の草原と西大陸の海岸に町を作った |
| 王国の衰え（星暦 900 年〜） | 竜気が強まって魔物が増え、王国は都のまわりしか守れなくなった。町は自分たちで身を守るようになり、冒険者ギルドが生まれた |
| 現在（星暦 1024 年） | 天の頂で地鳴りが続き、星が勇者に加護を貸しはじめた |

## 勇者たちの旅

- 勇者は毎朝、決まった回数だけ行動する。道を進むと、魔物に出会ったり、宝箱を見つけたりする
- 町に着くと傷が癒え、店で装備と回復薬を買い、ギルドの掲示板から依頼を 1 つ受ける。依頼は早い者勝ち
- 依頼をこなすと経験値とお金が入り、町によっては珍しい装備（★★ 以上）も手に入る
- 3 か月で星が巡ると、レベルは 1 に戻る。手に入れた装備だけは、次の巡りに持ち越せる
